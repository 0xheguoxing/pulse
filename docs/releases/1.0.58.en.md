This release adds the built-in Pulse assistant, a command palette, network locations, phones and cloud file status; Quick Look and thumbnails are faster and more capable, text is crisper, and Pulse starts faster and uses less power.

### Highlights

- [New] Pulse assistant: press Ctrl+J. Connect DeepSeek or another OpenAI-compatible service, then find files, batch rename, organize folders, find duplicates, check disk usage and adjust layout or settings with a sentence, by voice if you like. Pulse asks before it changes files; a multi-step task takes one confirmation and one undo.
- [New] Command palette: type > or press Ctrl+Shift+K to find and run any Pulse command.
- [New] Tap Ctrl twice for quick search, with the folders you use most ranked first. Other apps' Open and Save dialogs get a jump bar that takes them to a folder open in Pulse.
- [New] Network locations: the Network locations sidebar entry lists PCs and NAS devices on your network; Connect to server opens a share from its address, and recent servers are remembered.
- [New] Phones: a connected phone shows up in This PC and the sidebar; browse, copy and create folders, with the same context menu as File Explorer.
- [New] Cloud file status: OneDrive and other sync folders get a Status column; choose Always keep on this device or Free up space, and use Download and preview for online-only files.
- [New] AI enhancement pack: AI clients that support MCP, such as Claude, can find and organize files through Pulse; Pulse asks before a client connects or changes anything, and changes can be undone.
- [New] Photo wall: photos and videos keep their own shape in justified rows, so about twice as many fit on screen.
- [New] Favorites bar: a new bar under the command row; drag folders onto it, group them, and reach it with F6.
- [New] Tag management: tag groups and a combined tag view; Manage tags finds missing tagged files, with auto rules and import/export.
- [Setting] Backup & transfer: export or import all settings in one step; Pulse backs up first so you can restore. (Settings › About & diagnostics)

### Browsing and views

- [New] Aliases: press Shift+F2 to give a file or folder an alias, then find it by alias or pinyin.
- [New] Git: see file status inside repositories, and pull or push directly.
- [New] Win+E opens a new Pulse window; Shift+double-click opens a folder in a new window. Ctrl+N no longer opens a new window.
- [Setting] Single-click to open files and folders. (Settings › File list)
- [Setting] Select items with check boxes, no Ctrl needed. (Settings › File list)
- [Setting] Show a small mark next to aliases, off by default. (Settings › File list)
- [Setting] Interface transparency: set how see-through the sidebar and title bar are. (Settings › General)
- [Improved] Column view now works like Finder, so stepping through folders feels natural.
- [Improved] Folders expanded in Details view refresh by themselves; parent folders stay pinned at the top while you scroll, with tree guide lines.
- [Improved] With many tabs open, tabs keep their titles and the strip scrolls.
- [Improved] Quick access can be edited and reordered by dragging, and now includes Pictures, Videos, Documents and Music.
- [Improved] Each folder remembers its own icon size and folders-first choice; picture folders default to large icons.
- [Improved] A File name extensions switch on the toolbar; clicking empty space clears the selection.
- [Improved] This PC is grouped into drives, devices and cloud drives, each cloud drive with its own icon.
- [Improved] Friendlier dates: this week shows "Tue", a few days earlier "last Fri".
- [Fixed] More accurate preview colors for PSD and WebP transparency and for images with color profiles.
- [Fixed] Deleted default tags no longer come back; pinned tabs survive closing one of several windows.

### Quick Look and thumbnails

- [Improved] Quick Look redesign: rotate images and see their details, a video bar that fades away, a reading mode and contents for text, column types for tables, JSON paths, a hex ruler, and workbook sheet tabs in the footer.
- [Improved] Much faster thumbnails: parallel decoding, camera previews and the system cache first, and the next screen loaded ahead.
- [Setting] See how much space the thumbnail cache uses and clear it. (Settings › File list)
- [Fixed] Images open in a preview can be deleted; DNG photos are rotated correctly; .ts code files are no longer treated as video.

### Network and cloud

- [Setting] Discover network devices, remember recent servers, and show hidden shares. (Settings › File operations)
- [Improved] Browsing cloud folders no longer downloads online-only files.
- [Improved] Copying and deleting many files on network shares is faster.
- [Fixed] Opening several network shares at once no longer makes them all fail.
- [Fixed] Pulse no longer touches WSL shares in the background.

### File operations

- [New] Batch rename rebuilt: combine rules as steps, compare old and new names live, save presets and undo afterwards; or describe the rule in a sentence and let the Pulse assistant build it.
- [New] Hold Alt while dragging to create shortcuts.
- [Improved] Copy, move and delete are noticeably faster; large files show live progress, and Pause takes effect immediately.
- [Improved] A failed item no longer stops the operation; retry just the failed items at the end, and Undo reverses only what succeeded.
- [Improved] Redesigned progress, conflict, permanent delete and file-in-use dialogs; the progress card closes 3 seconds after it finishes.
- [Improved] Empty the Recycle Bin directly, restore items the way File Explorer does, and see folder sizes there.
- [Improved] Items copied to the other pane are selected afterwards.
- [Fixed] A failed move to the Recycle Bin never silently becomes a permanent delete.
- [Fixed] Dropping files on a shortcut keeps its own arguments; shortcuts some installers create open correctly.
- [Fixed] Run as administrator and Set as desktop background work again; Pin to taskbar also appears in the Windows 10 context menu.

### Search and toolbar

- [Setting] Search & indexing master switch: turning it off stops the index service without an administrator prompt. (Settings › Search & indexing)
- [Improved] Quick search redesigned and resizable; it also finds Start menu apps and aliased folders.
- [Improved] Advanced search redesigned.
- [Improved] Customizable toolbar: pin and reorder every command, and add separators.
- [Improved] Content search is now a downloadable enhancement pack.
- [Fixed] Content search retries by itself once a drive is enabled again, instead of staying on "not covered".

### Appearance, settings and performance

- [Setting] Custom accent color. (Settings › General)
- [Setting] Compatible opening: if double-clicking a folder does nothing, turn this on so File Explorer opens it first and hands it to Pulse. (Settings › Startup & integration)
- [Improved] macOS-style text rendering makes Chinese and English text crisper and easier on the eyes.
- [Improved] Dialogs use the system acrylic backdrop, with rounded corners and shadows on Windows 10 too.
- [Improved] Settings are reorganized into groups, so options are easier to find.
- [Improved] Faster startup: the window appears first and the rest loads afterwards; the program is smaller.
- [Improved] Almost no CPU when idle: background work wakes only when needed, and hovering redraws only the rows that change.
- [Improved] Smooth animations for menus, the sidebar, tabs, Quick Look and more.
- [Fixed] An occasional crash with some input methods, such as Sogou.
- [Fixed] An occasional blank window after resizing; the scroll bar in Settings can be dragged.

### Installation

- The portable (ZIP) edition is discontinued; please use the installer. Existing portable copies keep working; to keep getting updates, install Pulse with the installer.
