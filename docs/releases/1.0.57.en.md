### View

- New Photo wall: photos and videos keep their own shape in justified rows instead of square crops, so about twice as many fit. Names appear on a picture while it is hovered or selected. Switch from the pane header or the View menu; the icon size slider sets the row height.
- The first time a mostly-photo folder shows as icons, Pulse offers the photo wall once, with Switch or Don't show again.
- Picking an icon size in the View menu (or Ctrl+Shift+1…8) returns to the plain grid.

### File operations

- Much faster copy, move and delete: small files copy in parallel, large files no longer hold them up, and HDDs and large files bypass the system cache.
- Redesigned progress card with live progress for large files, instant pause and stable speed and time left.
- Items that fail are skipped and listed at the end; retry just those. Undo reverts only what succeeded.
- Redesigned conflict, permanent delete and file-in-use dialogs.
- Safety: a failed recycle never turns into a permanent delete, and a move removes its source only after the copy is verified.

### Search and indexing

- New Search and indexing master switch: turning it off stops the index service without an admin prompt; you can also delete the index files.
- Redesigned, resizable quick search popup.
- Faster name filtering, index merges and network scans with much lower memory use.
- Content search is now a downloadable enhancement pack that indexes your user folders.

### Toolbar, aliases and staging tray

- Customizable toolbar with a popover picker and drag reordering.
- Aliases (Shift+F2) show in the list, tabs, sidebar and address bar, and can be searched by alias or pinyin.
- Redesigned staging tray: pick items, drag them out, hide it while empty.

### Interaction

- Smooth motion across menus, sidebar, toolbar, columns, tabs, toasts and quick preview.
- Marquee selection from row whitespace (Ctrl inverts); Ctrl+arrows move focus without selecting, like File Explorer.
- New and pasted items appear in sort order and are selected.

### Context menu (Windows 10)

- Pin to taskbar now appears on Windows 10.
- Create shortcut, Format and Rotate stay when a menu tool turns Send to off.
