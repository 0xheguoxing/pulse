Network locations, phones, cloud file status and an AI assistant arrive in this release; text is crisper, and Pulse starts faster and uses less power.

### Highlights

- [New] Network locations: the Network locations sidebar entry lists PCs and NAS devices on your network; Connect to server opens a share from its address, and recent servers are remembered.
- [New] Phones: a connected phone shows up in This PC and the sidebar, so you can browse its photos and files.
- [New] Cloud file status: OneDrive and other sync folders get a Status column; choose Always keep on this device or Free up space, and use Download and preview for online-only files.
- [New] AI assistant: with the AI enhancement pack, AI clients such as Claude can find and organize files through Pulse; Pulse asks before a client connects or creates files, and changes can be undone.
- [New] Photo wall: photos and videos keep their own shape in justified rows, so about twice as many fit on screen.
- [New] Favorites bar: a new bar under the command row; drag folders onto it, group them, and reach it with F6.
- [New] Tag management: tag groups and a combined tag view; Manage tags finds missing tagged files, with auto rules and import/export.
- [Setting] Backup & transfer: export or import all settings in one step; Pulse backs up first so you can restore. (Settings › About & diagnostics)

### Browsing and views

- [New] Aliases: press Shift+F2 to give a file or folder an alias, then find it by alias or pinyin.
- [New] Git: see file status inside a repository and pull or push from Pulse.
- [Setting] Single-click: open files and folders with one click. (Settings › File list)
- [Setting] Use check boxes to select items: tick items to select several without Ctrl. (Settings › File list)
- [Setting] Show a mark beside aliases, off by default. (Settings › File list)
- [Improved] The column view works like Finder.
- [Improved] Quick access is editable and adds Pictures, Videos, Documents and Music.
- [Improved] Each folder remembers its icon size; picture folders open in large icons.
- [Improved] This PC groups drives, devices and cloud drives, and cloud drives show their own icons.
- [Improved] Easier dates: days this week read as Tuesday, earlier ones as Last Friday.
- [Fixed] Transparency in PSD and WebP files and pictures with colour profiles preview in the right colours.
- [Fixed] Deleted default tags stay deleted.

### Network and cloud

- [Setting] Find devices on this network, Remember recent servers and Show hidden shares. (Settings › File operations)
- [Improved] Browsing a cloud folder never downloads online-only files by itself.
- [Fixed] Opening several network shares at once no longer fails for all of them.
- [Fixed] Pulse no longer touches WSL shares in the background.

### File operations

- [New] Hold Alt while dropping to create shortcuts.
- [Improved] Much faster copy, move and delete, with live progress for large files and an instant pause.
- [Improved] A failed item no longer stops the rest; retry just the failed ones afterwards. Undo reverts only what succeeded.
- [Improved] Redesigned conflict, permanent delete and file-in-use dialogs.
- [Improved] The Recycle Bin empties directly, restores like File Explorer and shows folder sizes.
- [Improved] Items copied to the other pane are selected.
- [Fixed] A failed move to the Recycle Bin never turns into a permanent delete.
- [Fixed] Dropping files on a shortcut keeps the shortcut's arguments, and shortcuts some installers create open again.
- [Fixed] Run as administrator works again, and Pin to taskbar appears in the Windows 10 context menu.

### Search and toolbar

- [Setting] Search and indexing master switch: turning it off stops the index service without an admin prompt. (Settings › Search & indexing)
- [Improved] Redesigned, resizable quick search that also finds Start menu apps.
- [Improved] Customizable toolbar: pin and reorder any command and add separators.
- [Improved] Content search is now a downloadable enhancement pack.

### Appearance, settings and performance

- [Setting] Custom accent color. (Settings › General)
- [Setting] Compatibility mode: turn on if double-clicking a folder does nothing; File Explorer opens it first and hands it to Pulse. (Settings › Startup & integration)
- [Improved] UI text is rendered in a macOS-like style, crisper in both Chinese and English.
- [Improved] Settings are regrouped so options are easier to find.
- [Improved] Faster start: the window appears first and the rest loads after; a smaller program.
- [Improved] Almost no CPU while idle: background work wakes only when needed, and hovering redraws only the rows that change.
- [Improved] Smooth motion across menus, the sidebar, tabs and quick preview.
- [Fixed] The window no longer occasionally turns blank after resizing, and the settings scroll bar can be dragged.
